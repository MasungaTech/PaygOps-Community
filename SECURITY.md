# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, Discord, or other public channels.

To report a vulnerability, go to the “Security and Quality” section of the Github repository and click “Report a vulnerability”. 

Provide:
   - A description of the vulnerability
   - The affected version or component
   - Steps to reproduce it
   - Its potential impact
   - Any suggested mitigation, if available

The maintainers will acknowledge the report, investigate it confidentially, and coordinate any disclosure with the reporter. Please do not publicly disclose the vulnerability until a fix or mitigation has been released.

The maintainers may:
- Ask for additional information
- Confirm or reject the vulnerability
- Collaborate privately with the reporter on a fix
- Publish a public GitHub Security Advisory once users can safely be informed
- Credit the reporter, subject to their agreement
